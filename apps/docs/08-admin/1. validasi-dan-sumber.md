## Ringkasan

Admin meninjau antrean menunggu validasi, memperbaiki data, menerbitkan atau menolak, input manual, kelola sumber, laporan sistem.

## Implementasi

- `app/services/admin.py`, `app/api/v1/admin.py` (hanya peran admin)
- GET /admin/antrean-validasi, GET/PUT /admin/beasiswa/{id}, POST terbitkan dan tolak, POST /admin/beasiswa, /admin/sumber, GET /admin/laporan
