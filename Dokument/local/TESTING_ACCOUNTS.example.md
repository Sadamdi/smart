# Akun uji (contoh format)

Salin berkas ini menjadi `TESTING_ACCOUNTS.local.md` (diabaikan git) dan isi di sana. Jangan menuliskan nilai nyata di berkas contoh ini.

| Peran | Email | Kata sandi | Keterangan |
| --- | --- | --- | --- |
| mahasiswa A | mahasiswa.a@example.com | (isi di berkas .local) | Profil lengkap, beberapa beasiswa tersimpan |
| mahasiswa B | mahasiswa.b@example.com | (isi di berkas .local) | Profil kosong; untuk uji akses silang |
| admin | admin@example.com | (isi di berkas .local) | Hanya di basis data dev dan test |

Dua mahasiswa dipakai untuk memastikan data A tidak muncul untuk B.
